# Inhalte und Ziel des Kurses
-Projekt 1: Bau von elementaren Logikgattern wie And, Or, Not, Multiplexor und mehr
- Projekt 2: Bau einer Familie von Addiererchips, die in der Konstruktion einer arithmetischen Logikeinheit (ALU) gipfelt
- Projekt 3: Aufbau von Registern und Speichereinheiten, die in der Konstruktion eines Random Access Memory (RAM) gipfeln
- Projekt 4: Erlernen einer Maschinensprache und Schreiben einiger anschaulicher Low-Level-Programme mit dieser Sprache
- Projekt 5: Verwendung des in den Projekten 1-3 gebauten Chipsatzes zum Bau einer Zentraleinheit (CPU) und einer Hardwareplattform, die in der Lage ist, Programme auszuführen, die in der in Projekt 4 eingeführten Maschinensprache geschrieben wurden
- Projekt 6: Entwicklung eines Assemblers, d.h. einer Fähigkeit, in symbolischer Maschinensprache geschriebene Programme in binären, ausführbaren Code zu übersetzen.


Sie werden die Hardware-Projekte auf Ihrem Heimcomputer mit Hilfe einer einfachen Hardware-Beschreibungssprache (HDL), die Sie im Kurs gelernt haben, und einem von uns zur Verfügung gestellten Hardware-Simulatorerstellen. Ein Hardwaresimulator ist ein Softwaresystem, das es ermöglicht, Logikgatter und Chips zu bauen und zu simulieren, bevor sie tatsächlich in Silizium umgesetzt werden. Das ist genau das, was Hardware-Ingenieure in der Praxis tun: Sie bauen und testen Computer in der Simulation, unter Verwendung von HDL und Hardware-Simulatoren.
